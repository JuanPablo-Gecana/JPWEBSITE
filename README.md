# Portfolio Website ni Jepe

Personal portfolio website of Juan Pablo R. Gecana (JP / Jepe), a student developer learning Full Stack Web Development.

## Overview

A dark, terminal-inspired single-page portfolio built with vanilla HTML, CSS, and JavaScript — no frameworks, no build tools, no dependencies beyond Google Fonts.

## Features

- **Typewriter animation** — cycles through `BUILDING` and `DEPLOYING` in the hero section
- **Tech stack showcase** — categorized into Frontend, Backend, Database, and Services
- **Project cards** — flip-reveal cards with hover slide-up overlay
- **Contact section** — email, phone, location, and social links
- **Back-to-top button** — appears after scrolling 400px

## Getting Started

No install or build step needed. Just open `main/portfolio.html` directly in a browser.

## Tech Stack

- HTML5
- CSS3 (vanilla)
- JavaScript (vanilla ES6+)
- Google Fonts — Aldrich, Chakra Petch, VT323

## Design

Dark terminal aesthetic with a black checkerboard background, white copy, and light-green (`#7ed687`) accents. Glass-surface panels, inline SVG icons, and scale/slide hover interactions.
